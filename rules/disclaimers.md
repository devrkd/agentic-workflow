# Rule: External Content Disclaimers

Single source of truth for AI-generated content disclaimers. All agents must use these exact formats — do not restate or paraphrase them in prompt or skill files.

## Task sources

The **first line** of any agent-created or agent-updated task content (in the provider bound to the `task` category) must be:

```
🤖 This was generated by AI, don't forget to verify before making any decision. Agent: <agent-name>
```

Replace `<agent-name>` with the invoking agent: `architect`, `developer`, or `orchestrator`.

## Documentation sources

**Prepend** a highlighted note block at the very top of any agent-created or agent-updated document in the provider bound to the `documentation` category:

```
> [!NOTE]
> 🤖 This was generated by AI, don't forget to verify before making any decision. Agent: <agent-name>
```

Replace `<agent-name>` with the invoking agent: `architect`, `developer`, or `orchestrator`.

## Scope

These disclaimers apply to:
- New tasks and sub-tasks in the `task` category source
- New or updated docs and ADRs in the `documentation` category source
- Task comments posted by agents (progress-review, outcome-verifier)

They do **not** apply to:
- Local scratch files under `.tmp/<task-id>/`
- Git commits or PR descriptions (use PR description template instead)
