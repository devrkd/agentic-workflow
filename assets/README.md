# Assets

## `mentat-icon.png` — main project icon

`assets/mentat-icon.png` is the main project icon: a 640×640 app-icon-style
square — a stylized head/brain with an "M", gears, and circuit traces, in
blue-grey tones. It is rendered at the top of the repository
[`README.md`](../README.md) via:

```html
<img src="assets/mentat-icon.png" alt="Mentat" width="160">
```

`assets/.gitkeep` keeps this directory present in the repository even before
the icon was added; it is redundant now and harmless to leave in place.
